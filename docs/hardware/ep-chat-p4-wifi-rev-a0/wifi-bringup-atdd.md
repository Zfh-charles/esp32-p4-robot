# P4 + C6 Wi-Fi 变体：ATDD 验收意图

本文固定的是外部行为、关键边界和可证伪证据，不固定永久的内部实现。参数可在 EVT 实测后调整，但不得跳过分层验收。

## 1. 板前门（原理图/PCB）

### A1：接口无冲突

- Given：当前音频、MIPI DSI、MicroSD、电量计接口保持不变。
- When：对 P4 全部网名、绑带脚、下载调试脚、未使用脚做原理图级审计。
- Then：C6 SDIO Slot1 的 GPIO14–19 与 reset GPIO54 无双重驱动、无隐蔽外设冲突；MicroSD 仍独占 Slot0 GPIO39–44。
- 反例：仅以 `config.h` 没有引用某 GPIO 作为“PCB 可用”的证据。

### A2：电源可验证

- Given：C6 可能出现约 382 mA Wi-Fi TX 峰值，模块供电不得低于 3.0 V。
- When：Wi-Fi 发射、长 TTS、背光和 SD 活动同时发生。
- Then：C6 模块脚、P4 核心和音频轨均保持在数据手册范围；无 brownout、爆音、音频欠载或显示复位。
- 证据：电源轨示波器截图、触发条件、探头位置、环境温度和负载记录。

### A3：RF 可制造

- Given：最终屏幕、排线、电池、扬声器和外壳已装配。
- When：在整机形态下测量多方向 RSSI/吞吐和失包。
- Then：板载天线满足目标，或在 DVT 前切换 MINI-1U 外接天线；不得用裸板桌面结果代替整机结果。

## 2. 驱动 bring-up 门

### B1：C6 可独立恢复

- Given：P4 已启动，C6 未响应或被人为复位。
- When：host 执行受控 C6 reset/re-init。
- Then：Wi-Fi 链路可恢复，P4 不重启，MicroSD/音频/显示仍可用；恢复有明确超时和失败状态。

### B2：SDIO 分级升速

- Given：首板未知 SI 裕量。
- When：依次使用 1-bit 低时钟、4-bit 20 MHz，再按测量提高时钟。
- Then：每一级在持续双向流量下零 CRC/超时异常，才允许升阶；出现错误则保留可回滚配置并检查硬件波形。

### B3：SD 与 Wi-Fi 并发

- Given：MicroSD 在 Slot0，C6 在 Slot1。
- When：持续读取表情素材，同时进行 Wi-Fi 双向吞吐。
- Then：SD 无重挂载/读错，Wi-Fi 无不可恢复超时，音频采集和播放无欠载，显示预算可主动降级。

## 3. 语音产品行为门

### C1：完整首轮对话

- Given：设备冷启动并连接已配置热点。
- When：用户唤醒、说话并请求一段正常回答。
- Then：MQTT 会话控制建立；UDP 上行 Opus 连续；收到 STT；下行 TTS 可听；字幕与必要 UI 正常；会话结束状态一致。

### C2：长回答和背压

- Given：设备正在接收一段至少覆盖多个网络缓冲周期的长 TTS。
- When：同时存在 SD 表情读取和低频显示更新。
- Then：音频不在中途静音，不因显示抢占而丢失后续播报；网络/音频优先级高于可丢视觉帧；缓冲回落后系统继续响应。

### C3：退出与第二轮唤醒

- Given：第一轮对话已正常结束或超时退出。
- When：用户再次唤醒并完成第二轮问答。
- Then：上行 Opus、STT、TTS、字幕和会话退出均重新闭环；不得停留在“正在聆听”假状态，也不得依靠整机重启恢复。

### C4：网络故障恢复

- Given：活动会话或待机期间人为断开 AP、DHCP 或上游网络。
- When：网络恢复。
- Then：连接按有界退避恢复；旧会话/旧音频不补播；C6 失败可单独重置；基础本地功能保持可用。

### C5：主动提醒

- Given：设备空闲且提醒队列为空/非空各一次。
- When：MQTT 门铃或 HTTP 兜底触发。
- Then：空队列静默；非空按现有 session/preemption 契约完成唤醒、取正文、TTS 和 ACK；未真正收到音频不得提前 ACK。

## 4. 升级与回滚门

### D1：双固件兼容

- Given：P4 host 固件与 C6 slave 固件独立版本化。
- When：仅升级其中一侧。
- Then：启动时完成协议版本协商；不兼容时进入可诊断的受限模式并允许回滚，而不是反复重启。

### D2：C6 更新中断

- Given：P4 通过 host OTA 更新 C6。
- When：中途断电或传输失败。
- Then：可用串口/治具或已验证的恢复路径重新写入；P4 仍能进入诊断模式。

### D3：云端 OTA 不被本地化破坏

- Given：正式版本启用了本地缓存/回滚策略。
- When：云端下发合法新版本。
- Then：设备仍能校验、下载、切换、健康确认和失败回滚；本地固件不成为永久死端。

## 5. 稳定性与发布门

- 每个可比较固件/硬件组合都有唯一 marker：P4 固件、C6 固件、PCB rev、BOM variant、热点环境。
- 区分人工断电、烧录复位、C6 单独复位、P4 PANIC、HP/INT WDT 和 brownout。
- 至少覆盖：冷启动、待机、连续多轮、长 TTS、主动提醒、弱网重连、SD+Wi-Fi+显示并发。
- 用 per-marker 平均寿命和崩溃指纹对比基线，不以单次“连上 Wi-Fi”或几小时无日志替代稳定性结论。
- 硬件发布前关闭 README 中的全部 `TBD_PHYSICAL`；未关闭项必须有正式偏差批准和回滚措施。
